# Helldiver2AutoCommand

绝地潜兵2 自动呼叫战备脚本 — Helldivers 2 Auto Stratagem Caller

## 功能

- **可视化战备选择界面** — 按分类浏览所有战备（武器、轨道炮击、飞鹰、防御装备、哨戒炮、载具、特殊、任务）
- **完整战备数据库** — 包含 80+ 条战备完整信息（型号、名称、指令码、描述）
- **搜索功能** — 按名称、型号或描述关键词快速过滤
- **自定义按键绑定** — 支持自定义方向键映射（默认 WASD）、战备激活键及按键延迟
- **自动执行** — 双击战备即可自动模拟按键输入指令

## 运行要求

- Python 3.8+
- `keyboard` 模块（用于模拟按键，需要管理员/root 权限）

## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

```bash
# 启动可视化界面
python app.py
```

1. 在分类标签页中浏览战备
2. 使用搜索栏快速查找
3. **双击**某个战备即可自动执行对应的按键指令
4. 点击右上角 **⚙ 按键设置** 自定义方向键映射

## 按键配置

默认按键绑定（可在设置中修改）：

| 方向 | 默认按键 |
|------|----------|
| ↑    | W        |
| ↓    | S        |
| ←    | A        |
| →    | D        |

- **战备激活键**: `Ctrl`（游戏中按住打开战备输入模式）
- **按键延迟**: `0.05` 秒

配置保存在 `config.json` 文件中。

## 项目结构

```

├── executor.py     # 按键模拟执行器

```

## 测试


## 注意事项

- 在 Windows 上，`keyboard` 模块需要管理员权限
- 在 Linux 上，需要 root 权限或将用户添加到 `input` 组
- 请确保游戏窗口处于前台运行状态
